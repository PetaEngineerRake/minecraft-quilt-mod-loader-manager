## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Mod Profile** | Save and switch between named Quilt modpack configurations |
| **Dependency Tree** | Visualize mod dependency relationships for your mod list |
| **Conflict Resolver** | Detect incompatible mods and version mismatches in your profile |
| **Update Checker** | Flag Quilt mods with available updates in your active profile |
